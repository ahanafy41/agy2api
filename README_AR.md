# agy2api (النسخة المعززة فائقة السرعة والمحسنة للأندرويد وتيرمكس) 🚀

سيرفر محلي متطور فائق السرعة يحول أداة **Google Antigravity CLI (`agy`)** الرسمية إلى واجهة برمجية متكاملة تدعم بروتوكول **OpenAI** وبروتوكول **Google Gemini API** الرسمي، مع دعم كامل للوسائط المتعددة (صور، ملفات PDF، فيديوهات، ويوتيوب) والتشغيل فائق السرعة عبر محرك العامل المسخن (Warm Worker).

---

## 🌟 أبرز المميزات الحصرية في هذه النسخة

### 1. محرك العامل المسخن فائق السرعة (Warm Worker Engine) ⚡
- **زمن استجابة أقل من 2.5 ثانية**: بدلاً من انتظار 15-20 ثانية لبدء بيئة Node.js في كل طلب، المحرك يظل نشطاً ومسخناً في الذاكرة الرام (RAM) عبر نمط `stream-json`.
- **التدوير التلقائي الاستباقي (Proactive Standby Rotation)**: يقوم بتجهيز عامل احتياطي في الخلفية تلقائياً ويبدل إليه في 0.0 ثانية لمنع تراكم المحادثات وسياق الجمل القديمة (Context Bloat) التي كانت تبطئ الاستجابة مع مرور الوقت.
- **مراقبة الخمول التلقائية (Idle Auto-Recycle)**: بعد 90 ثانية من الخمول، يتم تنظيف الجلسات وإعادة تدويرها تلقائياً لتوفير موارد الهاتف والذاكرة.
- **القضاء التام على العمليات المعلقة (Zero Zombie Processes)**: عزل العمليات في مجموعات مستقلة (`start_new_session`) وحذف مخلفات الجلسات المؤقتة تلقائياً.

### 2. الدعم الكامل للوسائط المتعددة (Multimodal Support) 🖼️📄🎬
- **الصور**: استقبال الصور المشفرة بـ Base64 عبر واجهات OpenAI أو Gemini وتحليلها بدقة.
- **المستندات والكتب (PDF)**: إرسال ملفات PDF المحلية واستخراج المعلومات والبيانات منها.
- **الفيديوهات والصوتيات**: دعم تمرير مقاطع الفيديو والصوت المحلية بمختلف الصيغ (MP4, MKV, MP3, WAV, etc).
- **فيديوهات YouTube**: دعم تمرير روابط اليوتيوب المباشرة للتلخيص والتحليل.
- **إدارة الكاش الذكية (`media_cache/`)**: حفظ مؤقت للملفات أثناء المعالجة ومسحها فوراً بعد اكتمال الرد لضمان عدم استهلاك مساحة الهاتف.

### 3. دعم متكامل ومخصص لبيئة تيرمكس وأندرويد ولينكس 📱🐧
- سكريبت تشغيل تفاعلي ذكي `start.sh` يفحص بيئة النظام والتسجيل المسبق في `agy`.
- سكريبت تشغيل كخدمة في الخلفية `launch.sh` (Daemon) للعمل في خلفية تيرمكس دون الحاجة لإبقاء الجلسة مفتوحة.
- سكريبت إيقاف آمن وحاسم `stop.sh` لإغلاق السيرفر وكافة المحركات التابعة له بضغطة زر.

### 4. التوافق المزدوج مع OpenAI و Google Gemini 🌐
- مسار **OpenAI**: `POST /v1/chat/completions` متوافق 100% مع كافة برمجيات ومكتبات الذكاء الاصطناعي (NextChat, LibreChat, Python SDK).
- مسار **Google Gemini**: `POST /v1beta/models/{model}:generateContent` يدعم استبدال عنوان السيرفر في تطبيقات الأندرويد وإضافات قارئات الشاشة (كإضافات Jieshuo / CSR) والعمل كبديل مجاني تماماً لمفتاح Google API.

## 📋 المتطلبات الأساسية

1. هاتف أندرويد مع تطبيق **Termux** (أو جهاز Linux / macOS / Windows).
2. تثبيت بايثون 3.10 أو أحدث (`pkg install python`).
3. تثبيت أداة **Google Antigravity CLI (`agy`)** الرسمية وتسجيل الدخول فيها بحساب جوجل مرة واحدة على الأقل.

## 🚀 التثبيت والتشغيل

### 1. تثبيت الاعتماديات:
```bash
cd agy2api
pip install -r requirements.txt
```

### 2. طرق التشغيل على تيرمكس ولينكس:

- **التشغيل كخدمة في الخلفية (الأفضل للاستخدام اليومي):**
  ```bash
  ./launch.sh
  ```
  *سيبدأ السيرفر فوراً في الخلفية على المنفذ `7862`، وستتمكن من إغلاق شاشة تيرمكس واستخدام الإضافات بحرية.*

- **التشغيل التفاعلي المباشر:**
  ```bash
  ./start.sh
  ```

- **إيقاف السيرفر في أي وقت:**
  ```bash
  ./stop.sh
  ```

### 3. التشغيل على أنظمة Windows:
```cmd
start.bat
```

## 📡 أمثلة الاستخدام عبر الـ API

المنفذ الافتراضي: `http://127.0.0.1:7862`  
المفتاح الافتراضي (Bearer Token): `pwd`

### 1. طلب محادثة نصية عادية (OpenAI Format):
```bash
curl -X POST http://127.0.0.1:7862/v1/chat/completions \
  -H "Authorization: Bearer pwd" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.8-flash-low",
    "messages": [
      {"role": "user", "content": "مرحبا! عرف نفسك باختصار"}
    ]
  }'
```

### 2. طلب تحليل صورة عبر Base64 (OpenAI Format):
```bash
curl -X POST http://127.0.0.1:7862/v1/chat/completions \
  -H "Authorization: Bearer pwd" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.8-flash-low",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "ماذا يوجد في هذه الصورة؟"},
          {
            "type": "image_url",
            "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQSkZJRg..."}
          }
        ]
      }
    ]
  }'
```

### 3. طلب عبر مسار Google Gemini المباشر (للربط مع تطبيقات الأندرويد والجيشو):
```bash
curl -X POST http://127.0.0.1:7862/v1beta/models/gemini-3.8-flash-low:generateContent \
  -H "Authorization: Bearer pwd" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "parts": [
          {"text": "صحح هذه الجملة بالعامية المصرية: عامل ايه يا غالي"}
        ]
      }
    ]
  }'
```

## ⚙️ أهم متغيرات البيئة (Configuration)

| المتغير | الوظيفة | القيمة الافتراضية |
| :--- | :--- | :--- |
| `PORT` | منفذ السيرفر المحلي | `7862` |
| `HOST` | عنوان ربط السيرفر | `127.0.0.1` |
| `AGY2API_KEY` | مفتاح الحماية المحلي (Bearer) | `pwd` |
| `AGY2API_WARM_WORKER` | تفعيل محرك التشغيل المسخن فائق السرعة | `1` (مفعل) |
| `AGY2API_MAX_CONCURRENCY` | الحد الأقصى للطلبات المتزامنة | `3` |
| `AGY_TIMEOUT` | أقصى وقت انتظار للطلب بالثواني | `300` |

## 📱 الربط مع قارئ الشاشة الصيني (Jieshuo / CSR)

في إضافات الجيشو (مثل `asound` أو إضافة المساعد الذكي):
1. اضبط عنوان الخادم (Host): `127.0.0.1`
2. اضبط المنفذ (Port): `7862`
3. اضبط مفتاح الـ API: `pwd`
4. اختر الموديل: `gemini-3.8-flash-low` للإملاء الصوتي السريع، أو `gemini-3.8-flash-medium` للتحليلات الدقيقة.
